# BlackJack — Java Swing

Implementação acadêmica do jogo **BlackJack**, desenvolvida em Java com interface gráfica em Swing.

## Funcionalidades

- Partida single player contra o dealer
- Ações de pedir carta e parar
- Atualização da pontuação durante a rodada
- Interface gráfica desktop com Java Swing
- Regras básicas do BlackJack

## Tecnologias

- Java
- Java Swing

## Código do projeto

A versão original do código está armazenada no arquivo `BlackJack.rar`. Este repositório é mantido como registro de um projeto de estudo em Java desktop.
